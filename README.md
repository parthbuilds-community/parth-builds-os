## Resources

A collection of practical resources I've created and curated while learning, building, and navigating the developer journey.

You'll find resources covering:

- Development & Programming
- DSA & Problem Solving
- Projects & Building
- Developer Tools
- Internships & Careers
- Learning & Productivity

All resources are available in the resources/ folder.
```
parth-builds-os/
├── README.md
└── resources/
    ├── resource-1.md
    ├── resource-2.md
    ├── resource-3.md
    └── ...
```

The repository intentionally keeps a simple structure so resources are easy to find, use and contribute to.
